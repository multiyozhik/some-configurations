# Library - Библиотека

### Система учета книг с контролем мест хранения книг и их движений.

- Наименование книги формируется автоматически на основании Автора, Названия и характеристик Издательство, Издание, ГородВыпуска, ГодИздания.
- Реализовано хранение фото книги и оторажение на карточке Книги.
- Операции поступление книг, перемещение, продажа книг фиксируются документами.
- В отчете - список книг и мест размещения (отбор по характеристикам книг).


#### Детали реализации:

- Справочники  `Книги` (реквизиты `Автор, Название, Фото`), а также `Авторы`, `ПокупателиКниг`.
- Для возможных характеристик книг - справочники `Издательства, Издания, СпособыПечати, Ценности, ФорматыПечати, Шрифты, СтраныВыпуска, ГородаВыпуска`, а также `ДополнительныеЗначенияХарактеристик` (для добавления пользовательских реквизитов, владелец справочника - ПВХ).
- ПВХ `ХарактеристикиКниг`, тип значения характеристик - вышеперечисленные справочники по характеристикам + Строка, Число, дополнительные значения характеристик `ДополнительныеЗначенияХарактеристик`.
- для ПВХ регистр сведений `ЗначенияХарактеристикКниг`- непериодический, независимый (измерения `Книга, Характеристика`, ресурс `Значение`), где ресурс `Связь по типу - Характеристика, Связь параметров выбора - Отбор.Владелец(Характеристика)`.
- Документы `ПоступлениеКниг` и `ПеремещениеКниг` (ТЧ `Книга, Шкаф, Полка, Ряд`), а также `ПродажиКниг` (ТЧ `Книга, Покупатель`).
- РС `МестоХранения` - Подчинение регистратору, периодичность - По позиции регистратора (`Книга`, ресурсы `Шкаф, Полка, Ряд`).
- РС `Продажи` - непериодический, независимый (измерения `Книга, Покупатель`, ресурса нет).
