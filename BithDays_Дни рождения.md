# BithDays - Дни рождения

### Система учета поздравлений физических лиц, планирования поздравлений, контроля собранных средств и выдачи подарков.

#### Детали реализации:

- Справочник `ФизЛица` с указанием ФИО, даты рождения и пола.
- Документ `СборДенег` с указанием кто и сколько сдал на подарок, для кого предназначается сбор.
- Документ `ВыдачаДенег` на подарок с указанием кому и сколько выдано и для кого планируется покупать подарок.
- Документ `ПокупкаПодарка` с указанием кто покупает, кому и стоимости подарка.
- Документ `ВручениеПодарка` для фиксации факта вручения подарка с указанием даты.
- Использовались конструкторы на основании, на основании выдачи денег - покупка, на основании покупки - вручение подарка.
- Регистры накопления `СобранныеСредства` (измерения `КтоСдал`, `Именинник`, ресурс `Сумма`), `ПодотчетныеСредства` (измерения `КомуВыдано`, `Именинник`, ресурс `Сумма`).

- Т.к. поздравлять надо в рабочие непраздничные дни перед днем рождения, то регистры сведений `Производственный календарь` (измерение `Дата`, ресурс `ДеньРабочий`, форма списка с реквизитом `РежимРаботы`, команда `ЗаполнитьПроизводственныйКалендарь`).
- Для фиксации расчетной даты поздравления (вручения подарка) - регистр сведений `ПоздравленияИменинников` (измерения `ФизЛицо, Возраст, ДатаПоздравления`, ресурс `ПодарокВручен` типа Булево), расчет возраста - в общем серверном модуле `РаботаСоСпрвочниками`. Заполнение регистра поздравлений вызывается при заполнении производственного календаря.
- В справочнике `ФизЛица` - есть обработчики событий `ПередЗаписью` (для формирования ФИО на основе фамилии, имени, отчества), `ПриЗаписи` (для вызова метода модуля менеджера РС `ПоздравленияИменинников` при добавлении нового физ. лица) и `ПередУдалением` (для удаления соответствующей записи регистра).  
- Отчеты `Именинники`, `ПредстоящиеПоздравления`, `СобранныеСредства`.
